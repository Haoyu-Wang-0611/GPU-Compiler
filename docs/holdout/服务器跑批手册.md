## 3. 载具：接口 + 编译

### 3.1 接口（按现有源码核对）

| 载具 | 类型 | 接口 | 覆盖 |
|---|---|---|---|
| `sgemm_tiled` | **整轮扫参** | `SIZE [BM BN TK S]`（自己跑 48 配置） | R1/R2/R7 |
| `twomm_tiled` | **整轮扫参** | `SIZE [BM BN TK S]` | R3 |
| `3mm_tiled` | **整轮扫参** | `SIZE [BM BN TK S]` | R4 |
| `mvt_tiled` | **整轮扫参** | `N`（内部 T×TK×S） | R5/R8 |
| `bicg_tiled` | **整轮扫参** | `N` | R6 |
| `jacobi1d_8` | **整轮扫参** | `N`（`STEPS=8` 编译） | S6 |
| `jacobi2d_768` | **整轮扫参** | 无参（`N=768, TSTEPS=8` 编译） | S4 |
| `stencil1d_tiled` | 单配置 | `N T S R`（新） | S1/S2/S3/S7 |
| `stencil2d_tiled` | 单配置 | `N T S R`（新，条件） | S5 |
| `sgemm_rect` | 单配置 | `M N K BM BN TK S`（新，条件） | R9 |

**关键**：`holdout_sweep.sh` 已按这两类分开；`sgemm/twomm/3mm/mvt/bicg/jacobi*` 都是整轮扫参型，不要再按“每配置一次”去调。

**两处源码小改（若服务器版本与本地不一致，手工合）**：

> 编译时**不要用 `-DN`/`-DSTEPS`**（`N` 会替换 CUDA 头里的模板参数），用“复制一份源码 + `sed` 改 `#define`”。

```c
// jacobi2d_tiled.cu
#ifndef N
#define N 1024
#endif
#define INT_LO 1
#define INT_HI (N - 2)
#ifndef TSTEPS
#define TSTEPS 16
#endif
// 并把 printf 的 "N=1024, interior 1022" 改成 N / INT_HI

// jacobi1d_tiled.cu
#ifndef STEPS
#define STEPS 9
#endif
```

### 3.2 编译

```bash
cd "$BIN"
nvcc -O3 -arch=sm_89 -o sgemm_tiled      sgemm_tiled.cu
nvcc -O3 -arch=sm_89 -o twomm_tiled      twomm_tiled.cu
nvcc -O3 -arch=sm_89 -o 3mm_tiled        3mm_tiled.cu
nvcc -O3 -arch=sm_89 -o mvt_tiled        mvt_tiled.cu
nvcc -O3 -arch=sm_89 -o bicg_tiled       bicg_tiled.cu
# 两个编译期参数版：复制一份改 #define（不要用 -DN：N 会污染 cuda_pipeline.h 的模板参数）
cp jacobi2d_tiled.cu jacobi2d_768.cu
sed -i 's/#define N 1024/#define N 768/; s/#define TSTEPS 16/#define TSTEPS 8/' jacobi2d_768.cu
grep -n '#define N\|#define TSTEPS\|INT_HI' jacobi2d_768.cu
nvcc -O3 -arch=sm_89 -o jacobi2d_768 jacobi2d_768.cu

cp jacobi1d_tiled.cu jacobi1d_8.cu
sed -i 's/#define STEPS 9/#define STEPS 8/' jacobi1d_8.cu
grep -n '#define STEPS' jacobi1d_8.cu
nvcc -O3 -arch=sm_89 -o jacobi1d_8 jacobi1d_8.cu
# 新载具
nvcc -O3 -arch=sm_89 -o stencil1d_tiled  stencil1d_general.cu
# 条件（有源码才编）
nvcc -O3 -arch=sm_89 -o stencil2d_tiled  stencil2d_general.cu
nvcc -O3 -arch=sm_89 -o sgemm_rect       sgemm_rect.cu
```

### 3.3 单发自检（每个载具先跑一发）

```bash
CUDA_VISIBLE_DEVICES=$GPU "$BIN/sgemm_tiled" 1152 128 128 32 2 | tail -3
CUDA_VISIBLE_DEVICES=$GPU "$BIN/sgemm_tiled" 999  64 128 32 3 | tail -3
CUDA_VISIBLE_DEVICES=$GPU "$BIN/twomm_tiled" 1152 128 128 32 2 | tail -3
CUDA_VISIBLE_DEVICES=$GPU "$BIN/3mm_tiled"   1152 128 128 32 2 | tail -3
CUDA_VISIBLE_DEVICES=$GPU "$BIN/bicg_tiled"  1536 | head -3
CUDA_VISIBLE_DEVICES=$GPU "$BIN/stencil1d_tiled" 350000 512 1 2 | tail -3
CUDA_VISIBLE_DEVICES=$GPU "$BIN/jacobi2d_768" | head -5
CUDA_VISIBLE_DEVICES=$GPU "$BIN/jacobi1d_8" 12000000 | head -5
CUDA_VISIBLE_DEVICES=$GPU "$BIN/mvt_tiled" 1536 | head -5
```

每发必须看到 `PASS`，时间 >1 µs；`stencil1d_tiled` 的输出行必须是
`T=... S=... smem=...KB 实测: ... us  PASS`（`four_arms` 靠这个解析）。

## 5. 跑批（R=5）

```bash
cd "$WORK"
bash holdout_sweep.sh --list       # 看 kernel 名与类型
DRY=1 bash holdout_sweep.sh all    # 只打印命令（确认 argv）
bash holdout_sweep.sh all          # 正式跑
```

逻辑：

- 整轮扫参型（`sgemm/twomm/3mm/mvt/bicg/jacobi*`）：二进制跑 5 遍，每遍内部遍历全部配置；
- 单配置型（`stencil1d/2d`、`sgemm_rect`）：外层 5 轮 × 内层配置；
- 缺载具的 kernel 自动 skip；S5 没编就跳过（S7 副集单独报）。

跑批约 30–60 分钟 GPU；日志在 `$LOGS/`。

**中途检查**：

```bash
for f in "$LOGS"/*.log; do echo "== $f"; grep -c PASS "$f"; grep -c '实测\|耗时' "$f"; done
# <1µs 的立即停（launch 失败）
grep -E '实测:\s+[0-9]\.|耗时:\s+[0-9]\.' "$LOGS"/*.log | head
```

## 7. 故障处理

| 症状 | 处置 |
|---|---|
| `sgemm/twomm/3mm/mvt/bicg/jacobi` 日志一个 kernel 内有很多重复行 | 正常：整轮扫参型跑了 5 遍；`four_arms` 取中位数 |
| `jacobi2d_768` 打印 `N=1024` | `jacobi2d_768.cu` 的 `#define N` 没改到：`grep '#define N'` 检查后重编译 |
| `jacobi1d_8` 时间比预想大/小 8/9 | `jacobi1d_8.cu` 的 `#define STEPS` 没改到：`grep '#define STEPS'` 检查后重编译 |
| `nvcc` 报 `template<unsigned 768>` | 用了 `-DN=768`：改用上面的"复制 + sed 改 `#define`"，不要用 `-D` |
| `stencil1d_tiled` 没有 `实测:` 行 | 看 `FAIL/launch FAIL`；先修正确性再跑 |
| 某配置 `illegal memory access` | 停该 kernel；修载具；整份日志重跑 |
| 时间 <1 µs | 停；查 `cudaFuncSetAttribute` + 双重 `cudaGetLastError` |
| 跑批中途改了 binary/模型 | 本轮作废，全量重跑 |
| S5 载具没就绪 | 跳过 S5；S7 副集单独报；主集可测 11/12（≥10 仍有效） |
