

> 项目：基于 MLIR 的 GPU 数据分块(tile)与流水线深度(S)联合决策系统
> 一句话：输入 kernel 的 MLIR 代码 → 自动识别结构 → 毫秒级给出 tile/流水线参数 → 参数经 GPU 穷举实测验证 → 并能自动发射流水化代码（单 GEMM 全链路）。

## 一、依赖环境

- NVIDIA GPU（开发用 4090，sm_89）+ CUDA 12.6（nvcc）
- 一套开了 MLIR 的 LLVM 构建树（决策器 pass 链接 MLIR 库；服务器参考路径 ~/haoyu/llvm-project/build）

## 三、复现步骤

### 1. 编译决策器
```bash
cd ~/haoyu/l1-feas/build
cmake --build . -j 8        # 或 ninja -C . mlir-l1feas
```
（前提：LLVM_DIR/MLIR_DIR 指向一套开 MLIR 的 llvm-project 构建树）

### 2. 决策层回归（应与 E 组基线逐位一致）
```bash
L1=~/haoyu/l1-feas/build/mlir-l1feas
PASS='builtin.module(func.func(l1-feasibility{num-stages=3 tile-size=64}))'
cd ~/haoyu/scratch
for f in heat1d jacobi1d_big2 jacobi2d gemm4096 gemm512 gemm500 gemm1024 atax_big probe_dyn twomm; do
  $L1 $f.mlir -pass-pipeline "$PASS" -o /dev/null 2> l1_$f.txt
  echo "===== $f ====="; grep -E 'detected|Decision' l1_$f.txt
done
```

### 3. oracle 穷举（验证决策质量）
```bash
cd <cuda_oracle 编译目录>
nvcc -O3 -arch=sm_89 -o sgemm_tiled sgemm_tiled.cu
nvcc -O3 -arch=sm_89 -o twomm_tiled twomm_tiled.cu
CUDA_VISIBLE_DEVICES=1 ./sgemm_tiled 512 64 64 32 4      # 判定行应报 rank 3/48、距优 +5.4%、前20%达标
CUDA_VISIBLE_DEVICES=1 ./twomm_tiled 512 64 64 32 4      # 判定行应报 rank 3/48、距优 +9.7%、前20%达标
```

### 4. 发射（单 GEMM 全链路）
```bash
./run_pipeline_v5.sh ~/haoyu/scratch/gemm512.mlir
```

## 五、已知边界（复现时不要期望）

- 多 pass kernel（2mm 等）的**发射**未接通（决策已闭环，发射端 v1.8 待做）
- 非整除尺寸（500）的**发射**未验证（决策正确）
- bicg 的循环顺序形态、mvt 的融合形态会被决策器拒（模板缺口已登记）
- C 代码 → MLIR 前端自动化未做（Polygeist 与 LLVM 版本不兼容，方案已定：按其钉住版本独立构建）
